# M5 Windows 验收（0.5.0rc1）

此候选版在 Linux 环境完成自动测试；以下 Windows 双机及 Inno Setup 场景需要在用户的两台电脑上核对。

1. 在保留旧版 `%APPDATA%\AI Device Bridge` 的电脑上解压新版源码 ZIP，双击根目录 `Start-AI-Device-Bridge.bat`。首次打开应显示配置步骤；点“已了解，隐藏指引”后重新启动，步骤不再出现。已有配对、证书、接收授权码、计划、AI 计划证据和接收文件应保持。
2. 在未选择文件、设备或授权目录时检查按钮悬停提示；完成条件后按钮可用。修改并保存 Ollama 地址和模型，重启后应保留。
3. 建立多条计划和发送、接收记录，分别搜索文件名、设备、状态、方向；检查匹配结果和排序。点击“复制诊断信息”，粘贴到文本编辑器，确认版本、数据库版本、数据目录和日志路径正确，且不含接收授权码、对端授权码或私钥正文。
4. 用旧测试库验证“清理 30 天前的已结束历史”：确认框默认“否”；确认后旧的完成/失败/取消记录消失，近期记录与未完成记录保留，计划、配对和真实文件仍在。不要为了验收修改正在使用的数据库日期；可用自动测试覆盖旧记录场景。
5. 如使用安装版，先关闭旧程序，再运行同 `AppId` 的新版安装器覆盖安装。检查服务启动、配对、历史和接收文件；卸载后确认 `%APPDATA%\AI Device Bridge` 仍存在。安装器版本与源码版本均应为 `0.5.0rc1`。

若启动失败，记录错误框文字和诊断日志路径。数据库版本高于程序支持版本时，程序会阻止旧程序打开，避免误改较新数据库。升级前建议备份 `%APPDATA%\AI Device Bridge`。
