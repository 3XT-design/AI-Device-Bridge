# AI Device Bridge v1.0.0 · Windows x64

AI Device Bridge 帮助你在可互访的局域网电脑之间查找、确认并传输文件。

## 当前功能

- 配对设备并核对 TLS 指纹；为每台设备单独管理接收授权码。
- 手动选择文件，或用自然语言查找候选文件。
- 人工审核传输计划；每次上传前由接收端同意。
- 通过 HTTPS 传输文件，显示进度，并使用 SHA-256 校验完整性。
- 支持取消、失败后重试及传输历史查看。

## 下载

- `AI-Device-Bridge-Setup.exe`：Windows x64 安装包。
- `SHA256SUMS.txt`：安装包的 SHA-256 校验值。

两台电脑安装同一版本，并在可以互相访问的局域网内运行。首次配对请核对双方的 TLS 指纹，在接收电脑上为发送设备复制专用授权码。当前支持单文件传输，不支持文件夹同步或断点续传。
